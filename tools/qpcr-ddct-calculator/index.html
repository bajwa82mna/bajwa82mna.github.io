About and limitations

The default follows Livak and Schmittgen (2001); optional efficiency adjustment is based on Pfaffl (2001). It assumes independent technical-replicate errors, stable reference expression, and comparable samples. First-order propagation is an approximation and does not replace biological-replicate inference. Review amplification and melt curves separately. See methods and citations.

Frequently asked questions

Which method is used?

Livak 2^-ΔΔCt or optional efficiency adjustment.

How are replicates handled?

Technical replicate Ct values are averaged by sample and gene.

What warnings are shown?

Ct above 35, replicate SD above 0.5, and missing reference are flagged.

Is uncertainty propagated?

Yes, independent SE values use root-sum-of-squares.

Is data uploaded?

No; files and calculations stay in the browser.
