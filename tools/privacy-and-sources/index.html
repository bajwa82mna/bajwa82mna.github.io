Tool privacy, network use, sources and credits

The tools are local-first. This page records what stays in the browser, the exact actions that can make network requests, and the evidence and software behind the results.

How every tool processes data

Calculations, parsing, validation, matching, filtering, plotting, image resizing and export generation run in the browser. Local files are read with browser file APIs; the site does not receive them as uploads. Some journal and publishing workflows can request public metadata, but only after the user activates the labelled lookup, search, refresh or live-profile control. API responses may be cached in localStorage or IndexedDB on that device and can be cleared with the tool’s cache control.

Data sources and licences

  • OpenAlex: public scholarly metadata released under CC0.
  • DOAJ: journal metadata made available under CC0.
  • Crossref: publisher-deposited bibliographic metadata and update relations retrieved through the Crossref REST API. Retraction Watch records are accessed only through Crossref update metadata and are CC0.
  • Journal Timing: committed aggregate values derived from DOAJ journal data and Crossref records; article-level build responses are not distributed.
  • Citation.js 0.9.0: MIT-licensed local parsing for BibTeX, RIS and CSL-JSON.
  • qrcode-generator 1.4.4: MIT-licensed local QR rendering.
  • Fuse.js 7.5.0: Apache-2.0 local fuzzy search.
  • MiniSearch 7.2.0: MIT-licensed local lexical retrieval.
  • pica: not used or bundled; figure resizing uses the browser canvas implementation.

Version, author, retrieval, checksum and modification details are preserved in CREDITS.md, NOTICE and the linked licence files. No Clarivate, Scopus, CAS, Journal Impact Factor or bundled SCImago data is used.

What is never collected by the tool code

The repository’s tool code has no accounts, analytics, advertising trackers, tracking cookies, server upload endpoint or form for personal contact details. It does not collect manuscript text, pasted references, laboratory values, sequences, CSV files or images. Optional API providers receive only the fields listed above. Hosting infrastructure may still process routine delivery and security logs under the site-wide privacy policy.

Limits

  • Descriptive Statistics accepts CSV files up to 2 MB and 10,000 rows.
  • Variant Toolkit accepts up to 2 MB per VCF, GFF3 and FASTA input; it is for small teaching and preflight files, not genome-scale annotation.
  • Journal Figure Resizer accepts images up to 25 MB and caps output at 80 megapixels; practical memory limits depend on the browser and device.
  • Journal Hub shows one selected journal across its evidence sources; the embedded OA/APC comparison tray supports up to four journals.
  • API providers can return incomplete, delayed or conflicting metadata and can impose rate limits. A missing record is not a quality verdict.
  • Browser caches for live metadata expire after 30 days where used and can be cleared from the relevant tool.

Contact-free by design

There is no contact form, email address or phone number on this page. The tools do not ask for contact information.
