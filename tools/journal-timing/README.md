# Journal Timing

A static browser tool covering all 21,341 ISSN-joinable Emerging Journals 2026 identities through on-demand title indexes and hash-addressed timing shards. It combines prebuilt DOAJ self-reported publication weeks and Crossref date summaries, with an explicit per-journal live Crossref lookup for missing or updated evidence. See `METHODS.md` for parsing, suppression, sharding, caching, and resumable rebuild details.
