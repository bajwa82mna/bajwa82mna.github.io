Journal Trust Profile

Build a source-linked evidence card for a journal. Compare identity, open-access declarations, preservation, recent output, and conflicts without reducing them to a trust score or verdict.

Evidence aid · not an endorsement

Local search

Find a journal

Suggestions come from the smbajwa.com Emerging Journals 2026 dataset. A valid ISSN can be looked up even if it is not in the local seed.

Privacy and network use

Local suggestions and checklist notes stay in this browser. When you choose Build live profile, only the selected title/ISSN is sent to:

  • doaj.org
  • api.openalex.org
  • api.crossref.org

Responses are cached locally for 30 days. No manuscript, editor names, email addresses, API keys, or analytics are used.

Credits and limits

Journal Trust Profile by Shoaib Munir, smbajwa.com. Built on Fuse.js (Apache-2.0) by Kiro Risk and contributors. Evidence uses CC0 metadata from DOAJ and OpenAlex plus Crossref metadata and the locally curated smbajwa.com journal source.

This profile is not an endorsement, blacklist, legal finding, or substitute for checking the journal’s current policies. Missing metadata is not evidence of misconduct. No Clarivate, Scopus, CAS, JIF, blacklist, or watchlist data are included.

Evidence can be incomplete or stale. Review linked primary sources before submitting.
