Credits, scope and limits

Reference Integrity Checker by Shoaib Munir, smbajwa.com. Built on Citation.js 0.9.0 (MIT) by Lars Willighagen and contributors. Bibliographic metadata from Crossref; retraction metadata from Retraction Watch via Crossref (CC0). Optional secondary evidence comes from OpenAlex (CC0).

No database can establish that a paper is error-free. “No alert found” means only that no matching update was returned by the queried source; review linked primary records. This tool does not infer misconduct.
