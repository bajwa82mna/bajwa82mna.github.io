Open research tools

Seven browser-based workflows for literature, journals and plant-lab planning. Each tool states what stays local, which public services it contacts, and the limits of its evidence.

Emerging Journals Database 2026

Find journals in the translated 2026 quartile list and inspect open citation context.

Best for
Broad journal discovery
Input
Journal title, ISSN, or filters
Output
Sortable matching records
Open database →Try example

Reference Integrity Checker

Check a reference list for duplicates, mismatched metadata, and public update notices.

Best for
Pre-submission reference checks
Input
DOIs, references, BibTeX, RIS, or CSV
Output
Evidence report and CSV
Open checker →Try example

Identifier & Citation Toolkit

Clean and validate common scholarly identifiers, then retrieve selected public metadata.

Best for
Mixed identifier cleanup
Input
DOI, ISSN, ISBN, ORCID, or citations
Output
Validation and citation exports
Open toolkit →Try example

Journal Trust Profile

Gather source-linked journal identity, access, preservation, and output evidence.

Best for
Submission due diligence
Input
Journal title or ISSN
Output
Evidence dossier, not a score
Open profile →Try example

OA & APC Explorer

Compare open-access fee declarations, waivers, licences, and budget scenarios.

Best for
OA cost planning
Input
Journal, subject, or ISSN
Output
Comparison table and budget range
Open explorer →Try example

Plant Lab Calculator Suite

Run transparent qPCR, dilution, molarity, and primer-Tm calculations offline.

Best for
Bench planning and methods records
Input
Ct values, concentrations, mass, or sequence
Output
Calculated values and formulas

Abstract-to-Journal Matcher

Turn plant-science manuscript signals into a private, explainable journal shortlist.

Best for
Early journal discovery

Output
