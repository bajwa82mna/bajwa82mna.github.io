# Methods

SD is the sample standard deviation (n−1); SE is SD/√n. The 95% confidence interval uses a two-sided Student t critical value (tabulated approximations). Quartiles use the R-7 / Excel inclusive linear interpolation method, `h=(n−1)p`. Outliers are observations below Q1−1.5×IQR or above Q3+1.5×IQR. No observations are automatically removed.
