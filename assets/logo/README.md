# smbajwa.com logo

Original artwork. A tomato (the research organism) carrying a white "S" stroke that doubles as a DNA-strand curve; the leafy calyx stands for plant biology and open, growing tools.

## Files
- logo-mark.svg: square icon (512 viewBox), for light backgrounds and favicon source
- logo-horizontal.svg: mark + "smbajwa.com" wordmark (light backgrounds)
- logo-dark.svg / logo-mark-dark.svg: variants for dark backgrounds (lighter tile, off-white wordmark)
- favicon-32.png, favicon-180.png (apple-touch-icon), favicon-512.png
- preview.png: all variants on light and dark

## Colours
- Dark green #2f5d3a (tile, wordmark); dark-bg tile #3a7448
- Tomato red #d9482b (fruit, ".com"); on dark #f0795c
- Leaf green #8fc79a (calyx)
- Off-white #f7f8f4 (S stroke, dark-bg wordmark)

## Usage
- Favicon: `<link rel="icon" href="/logo-mark.svg" type="image/svg+xml">`, PNG 32 fallback, 180 apple-touch-icon.
- Keep clear space of about 1/4 of the mark width. Minimum size 16 px (mark) / 120 px wide (horizontal).
- Wordmark uses a generic font stack (Helvetica Neue, Helvetica, Arial, Segoe UI, sans-serif) bold, so it varies slightly by OS; convert to outlines in a vector editor if exact lettering is needed (e.g. print).
- Do not recolour the tomato or stretch the mark.
